# Macro calibration reports

Commit-safe **aggregates** from point-in-time replay over local `data/bars`.

- Regenerated by `npm run calibrate` (requires a prior `npm run ingest`).
- Does **not** embed Tiingo raw EOD. Per-day ledgers stay in gitignored `data/calibration/`.
- Report-only phase: parameters are not edited here; `calibrated` stays `false` until review.
